# IOT Home Automation System

# Overview
This project enables remote control of home appliances using ESP8266 and Wi-Fi communication.

# Features
- Remote appliance control
- Relay-based switching
- Mobile-based monitoring
- Wi-Fi communication

# Components Used
- ESP8266
- Arduino UNO
- Ultrasonic sensors
- Relay Module
- Bulb/Fan
- Wi-Fi Network

# Software & Interface
- Arduino IDE
- Blynk

# Applications
- Smart homes
- Energy management
- Remote monitoring

# Future Improvements
- Voice control
- AI automation
- Mobile app integration
